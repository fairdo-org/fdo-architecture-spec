[S-2]: Resolution of PIDs

This process shall resolve the PID using the resolvers from the list of IdentifierResolvers provided by [S-1].
Inputs
  • A list of IdentifierResolvers from [S-1]
  • An optional flag TRY_ALL that will try all resolvers. The default is to stop at the first successful resolution.
Outputs
For each resolver specified in ResolverList that succeeds, the following information is returned:
  • The name of the resolver
  • Resolution status: RESOLVED
  • The PID record

If the resolution is not successful:

  • The name of the resolver
  • Resolution status: NOT_RESOLVED
  • The resolvers error message if any
Expected behavior
The process will try each resolver until one is successful or, if specified by TRY_ALL, all resolvers. This process will return each resolver’s respective PID record. The process MUST prevent false positives.
