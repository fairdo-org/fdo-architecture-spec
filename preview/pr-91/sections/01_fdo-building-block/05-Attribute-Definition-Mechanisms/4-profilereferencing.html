[R-Attr-13] Profile Referencing

Profile referencing permits an attribute definition to specify that the value (of an attribute instantiating this attribute definition) MUST be a reference to an FDO following a profile from a set of allowed profiles P1,...,Pn, n≥0. Depending on how many profiles are allowed, the referenced entity MUST be one of:

  • (n=0) an FDO (i.e., complying with the root profile),
  • (n=1) an FDO complying with a specific profile P1,
  • (n>1) an FDO complying with at least one of the P1,...,Pn.

To register an attribute definition that uses profile referencing with the allowed profiles P1,...,Pn, the following requirements MUST be fulfilled:

  • The attribute definition record MUST use the profile 0.FDO/AttributeDefProfileRef (that is, it contains the attribute (0.FDO/Profile, 0.FDO/AttributeDefProfileRef)). This indicates that the attribute definition applies the profile referencing mechanism.
  • The attribute definition record MUST contain the attributes (0.FDO/AllowedProfileInProfileRef, PID of Pi) for i=1,...,n, to indicate which profiles are allowed, see also Table 7. If n=0, this requirement does not apply.
When the attribute definition is instantiated, the value MUST be either a validated reference to another FDO following at least one of the specified profiles, or an inline serialization of an FDO that instantiates at least one of the specified profiles.
