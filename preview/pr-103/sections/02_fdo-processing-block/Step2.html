[S-2]: Resolution of PIDs

This step assumes that has finished successfully and outputted an identifier_resolvers list. For the elements of identifier_resolvers, it now attempts to resolve the identifier using the different resolvers.
Inputs
  • A list of objects as outputted by
  • try_all: An optional flag that will try all resolvers. The default is to stop at the first successful resolution.
Outputs
A list of objects is returned where each object is of the form:
  • identifier: the tested identifier
  • resolver: the name of the tested resolver
  • status: RESOLVED or NOT_RESOLVED
  • pid_record: the PID record, if resolution was successful
  • error_message: the resolvers error message if any, if resolution was not successful
Expected behavior
For each element of identifier_resolvers, the process will try each resolver on the identifier until one is successful or, if specified by try_all, it will try all resolvers. This process will return each resolver’s respective PID record. The process must prevent false positives.
