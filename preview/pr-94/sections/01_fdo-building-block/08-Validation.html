Validation

Validation is a key characteristic of FDOs. It enables detecting errors in the FDO Record early on. Validation SHOULD at least be carried out upon creation and update of an FDO.

[R-VAL-1] FDOs

Every FDO instance must be valid against 0.FDO/Root.

[R-VAL-2] FDO Profiles

Every profile must be valid against 0.FDO/ProfileDef.

[R-VAL-3] FDO attributes

Every attribute value must be valid against its definition 0.FDO/AttributeDef.

[R-VAL-4] FDO Profile Extensions

A profile must be valid against all profiles it extends.
