Introduction

This specification adds reliable machine interaction to Persistent identifiers (PIDs) by proposing a flexible framework to assign precisely structured metadata to a PID. It aims to be a generic but flexible interoperability layer for fast and reliable automated processing on top of all kind of (research) data.

A PID describing data using this framework is called a FAIR Digital Object (FDO). With this metadata, the aim is to make FDOs machine-actionable units, ready for highly automated processing or AI use. Given these properties, FDOs form a harmonization layer for arbitrary data.

If an FDO client finds a PID that identifies an FDO, it is able to automatically interpret and process the FDO, regardless of the technology used to implement the concept. This specification is the basis for this kind of interoperability.

In a more elaborated fashion, a FAIR Digital Object (FDO) is a predictable, standardized and persistent resource of information that represents (i.e., identifies and describes) a digital or physical resource which can be of any type (data, metadata, semantic assertions, configurations, AI models, etc.) and complexity. It does not necessarily contain the data itself. From the view of data, an FDO is a concept and a process to describe the data and how to access it. Every FDO implements the FAIR principles [[FAIR]] and complies by-default with these principles:

  • An FDO is identified by a globally unique, persistent, and resolvable identifier known as a PID).
  • A PID resolves, directly or indirectly, to a structured, machine-actionable metadata record that describes the identified resource.
  • The machine-actionable record contains or has external reference(s) to the resource's data bit-sequence and associated metadata bit-sequence(s), when appropriate.
  • An FDO should include license and provenance information, and standard, domain-specific metadata.

FDOs are an implementation of the FAIR principles that can improve data sovereignty, transparency/traceability, accountability, interoparability and persistence. These characteristics are critical when establishing a stable, robust, and highly distributed ecosystem of data, which includes well-documented AI models and their training corpus. Society, businesses and governments will increasingly depend these FDO caracteristics to establish trust in data and data services. While FDOs can be passive units of information they can be directly associated with executable operations which can be used for data encapsulation and faciliatate autonomously acting agents.

FDO characteristics and properties, provide a common harmonization layer for the many existing and emerging dataspaces in science and industry. They specifically provide solutions for the trust, control and data planes of dataspace.

Origin of this document

The concept of FAIR Digital Object (FDO) emerged from meetings, in the fall of 2019 consisting of representatives from the Research Data Alliance (RDA), the FAIR community and other organizations that all recognized the potential of FAIR as well as the need to further its technical development. The FAIR community had identified that machine actionability [[Jacobsen2020]] and interoperability were key FAIR requirements. The RDA had determined that Digital Objects (DO), as described in a seminal paper on the Digital Object Architecture (DOA) by Kahn and Wilensky [[Kahn-Wilensky]], represent a foundational core architectural component that enable machine actionable data management, and facilitate interoperability and reusability that could directly address these FAIR requirements.

These meetings resulted in an agreement between the various representatives to collaborate on the elaboration of data infrastructure technologies, the definition of FDO technical requirements and the creation of a governance structure to advance FDO development.

This FDO specification document is a result of this collaboration, under the governance of the FDO Forum, and it specifies how Digital Objects, as the core architectural component, can be used to implement the FAIR principles. The FDO Forum is an international, independent organization that specifies FDOs and best practices, organizes the FDO community, and coordinates FDO implementations and applications. It is not yet a legal entity, therefore, it will need to be represented by an existing organization until it becomes a legal entity.
