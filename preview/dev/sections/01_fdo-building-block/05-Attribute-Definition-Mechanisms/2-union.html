Union of Attribute Definitions

An attribute definition MAY be defined to be a union of attribute definitions A1,...,An, n≥1. If an attribute definition is a union, this means that any attribute instantiating this attribute definition MUST have a value complying with at least one of the A1,...,An (a.k.a. “any of”). The cardinalities of A1,...,An are overwritten by the cardinality of the union.

To define an attribute definition as a union, the attribute definition record MUST use the profile 0.FDO/AttributeDefUnion. This profile extends the attribute definition profile with the attribute 0.FDO/AllowedAttributeInUnion (see Table 5). This attribute lists as its values all attribute definitions A1,...,An that are part of the union.
