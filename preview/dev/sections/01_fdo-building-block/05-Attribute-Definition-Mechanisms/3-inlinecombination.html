[R-Attr-13] Inline Combination of Attribute Definitions

An attribute definition MAY be defined to be an inline combination of attribute definitions A1,...,An, n≥1. If an attribute definition is an inline combination, this means that any attribute instantiating this attribute definition MUST have as its value a combination of values v1,...,vn that instantiate A1,...,An (a.k.a. “all of”). The combination of v1,...,vn must respect the cardinalities of A1,...,An, as long as those are not restricted further in the attribute definition of the inline combination (see 0.FDO/AllowedAttributeInCombination). The format of this combination (e.g., JSON, JSON-LD, …) MAY depend on the implementation.

To define an attribute definition as an inline combination, the attribute definition record MUST use the profile 0.FDO/AttributeDefComb. This profile extends the attribute definition profile with the attribute 0.FDO/AllowedAttributeInCombination (see Table 6). This attribute lists as its values all attribute definitions A1,...,An that are part of the inline combination.


This table shows the 0.FDO/AttributeDefComb profile. The profile extends the attribute definition profile (see Table 3). All attributes that are inherited from the attribute definition profile are left out for brevity. To define that an attribute definition is an inline combination of other attributes A1,...,An, the 0.FDO/AllowedAttributeInCombination must be instantiated in an attribute definition, once for each of the A1,...,An.
