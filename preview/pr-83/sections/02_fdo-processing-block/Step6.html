[S-6]: FDO Profiles Inspection

This step determines whether the FDO record’s profiles are the same or compatible with the FDO profile the client expects to process. This step assumes that was completed and that its status indicates that a 0.FDO/Profile attribute is present (i.e., COMPLETE, PROFILE_ONLY, TYPE_MISSING, or DATA_MISSING). This step is analog to the FDO type inspection step.

Inputs
  1. an FDO record: This step expects exactly one well-structured FDO record. Typically, this is the output of .
  2. expected_fdo_profile_list: A list of profiles that the client is looking for. It can be empty indicating that any FDO profile within the FDO record will be accepted. This forces the ACCEPT_ANY flag described below.
  3. A matching flag:
    • ACCEPT_ANY: Any FDO profile is acceptable. This ignores the expected_fdo_profile_list if provided.
    • EXACT_MATCH: Every FDO profile in the FDO record must match any of the FDO profiles in the expected_fdo_profile_list.
    • DERIVED_MATCH: The FDO profiles in the FDO record can be derived profiles from the expected_fdo_profile_list. Derived profiles are backward compatible with their parent profiles.
Outputs
This step returns
  • status: FULL_MATCH, ALL_MATCH, PARTIAL_MATCH, DERIVED_MATCH, or NO_MATCH. For details, see the expected behaviour below.
  • profile_matching: a list of the FDO profiles that match or are derived from the expected profiles. If the list is empty, it indicates that none were found. The client can determine from the number of FDO profile matches whether the match is full or partial.
Expected behavior
The client will compare the list of FDO profiles in the FDO record with the expected_fdo_profile_list looking for matches. The expected behavior is completely analog to .

This example shows a simple FDO record 21.1234/777 with two FDO profiles 21.123/Profile1 and 21.123/Profile2. Adding to the example is the fact that the FDO profile 21.123/Profile1 is derived from the FDO profile 21.123/Profile0.

Applying the processing step delivers
  • FULL_MATCH for an empty expected_fdo_profile_list
  • ALL_MATCH for the expected_fdo_profile_list [21.123/Profile1, 21.123/Profile2]
  • PARTIAL_MATCH for the expected_fdo_profile_list [21.123/Profile1, 21.123/my_profile]
  • NO_MATCH for the expected_fdo_profile_list [21.123/Profile0], but DERIVED_MATCH if the matching flag is set to DERIVED_MATCH
