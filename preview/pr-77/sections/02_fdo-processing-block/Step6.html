[S-6]: FDO Profile(s) Inspection

This step determines whether the FDO record’s profiles are the same or compatible with the FDO profile the client expects to process. This step assumes that was completed and that its status indicates that a 0.FDO/Profile attribute is present. This step is in analog to the FDO type inspection step with the only difference that a profile specifies the set of fields that an FDO record SHOULD have to describe a particular type of objects.

Inputs
This step expects that had a status of COMPLETE, REQUIRED_FIELDS, PROFILE_ONLY and two inputs:
  1. The list of profiles that the client is looking for. This is called the Expected_Fdo_Profile_List.
  2. The Profile_Matching flag. The three possible values are:
    • ALL_MATCH: Indicates that any FDO profile is acceptable. This ignores the Expected_Fdo_Profile_List if provided.
    • EXACT_MATCH. Indicates that the FDO profile matching requires an exact match with the FDO profiles in the Expected_Fdo_Profile_List.
    • DERIVED_MATCH. Indicates that the FDO profiles in the FDO record can be derived profiles from the Expected_Fdo_Profile_List. Derived profiles remain backward compatible with their parent profiles.
Outputs
This step returns
  • the Profile_Matching_Status: FULL_MATCH, ALL_MATCH, PARTIAL_MATCH, DERIVED_MATCH, or NO_MATCH
  • a list of the FDO profiles that match or are derived from the expected profiles. If the list is empty, it indicates that none were found. The client can determine from the number of FDO profile matches whether the match is full or partial.
Expected behavior
The client will compare the list of FDO profiles in the FDO record with the Expected_Fdo_Profile_List looking for matches. The expected behavior is completely analog to .

This example shows a simple FDO record 10.1234/777 with two FDO profiles 10.123/Profile1 and 10.123/Profile2. Adding to the example is the fact that the FDO profile 10.123/Profile1 is derived from the FDO profile 10.123/Profile0.

Applying the processing step delivers
  • FULL_MATCH for an empty Expected_Fdo_Profile_List
  • ALL_MATCH for the Expected_Fdo_Profile_List [10.123/Profile1, 10.123/Profile2]
  • PARTIAL_MATCH for the Expected_Fdo_Profile_List [10.123/Profile1, 21.123/my_profile]
  • NO_MATCH for the Expected_Fdo_Profile_List [10.123/Profile0], but DERIVED_MATCH if the Profile_Matching is set to DERIVED_MATCH
